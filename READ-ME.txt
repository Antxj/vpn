VPN - OpenVPN connections with automatic Google Authenticator token
====================================================================

(Versão em português: LEIA-ME.txt)

WHAT IT IS
----------
A program that connects to one or several VPNs at the same time,
generating the Google Authenticator token by itself. You register each
VPN only once (the .ovpn file, username and password/seed - or import
the username and seed straight from the enrollment QR code) and then
just switch the account's toggle on. If a connection drops, it
reconnects by itself with a fresh token.

The interface follows the Windows language (English or Portuguese).

REQUIREMENTS
------------
1. Windows 10 or 11 with DirectX 12 support
2. The .ovpn configuration file of each VPN (the same one you would use
   in OpenVPN GUI, usually in C:\Users\YOUR_USER\OpenVPN\config)
3. For VPNs with a token: the seed OR the QR code image sent by support
   (the same one scanned with the Google Authenticator phone app)

OpenVPN does NOT need to be installed: the program ships the official
installer inside it and installs it by itself, with one click, if it is
missing. If OpenVPN Community is already installed, it uses that one.

The program runs as administrator (OpenVPN needs this to create the
network connection): Windows asks for permission every time it opens.

HOW TO USE
----------
1. Open VPN.exe and accept the administrator prompt.
2. If the yellow notice "OpenVPN Community is not installed" appears,
   click "Install now" and wait about a minute: the program installs
   the official OpenVPN by itself, without opening any window. When the
   notice goes away, you can continue.
3. Click "Accounts" and then "New account". Fill in:
   - Name: how the VPN will be shown (e.g. Work, Client X);
   - .ovpn file: click "Browse...";
   - Username;
   - Authentication: "Token (Google Authenticator)", "Fixed password"
     or "Password + token" (when the server expects the password
     followed by the 6-digit code);
   - Seed and/or password, depending on the authentication. For the
     seed, you can click "Import QR code..." and choose the QR code
     image (or paste a screenshot): username and seed are filled in by
     themselves. Compare the "Current token" shown with the phone.
   Click "Save". Repeat for each VPN.
4. On the home screen, switch the account's toggle on. When "Connected"
   appears in green, you are done. Several can be on at the same time.
5. Closing or minimizing the window does NOT disconnect: the program
   goes to the system tray (near the clock). The icon color shows the
   summary: gray = none connected, amber = some connecting,
   green = connected. Hovering over the icon lists each connection.
   A click reopens the window; the right button opens the menu, where
   you can turn each account on/off, "Disconnect all" and "Exit".
6. To quit for good, right-click the tray icon and choose "Exit" (all
   VPNs are disconnected).
7. Opening VPN.exe again while it is running just restores the window
   (it does not open a second copy).

FULL TUNNEL AND SPLIT TUNNEL
----------------------------
Each card shows the VPN type, learned on the first connection:
"all traffic" (full tunnel: everything goes through the VPN) or "VPN
network only" (split tunnel: only the company network goes through the
VPN). One of each can be on at the same time, in any order - the
program takes care of the routes so one does not knock the other off.
Two full-tunnel VPNs at the same time do not work properly, and the
program warns before connecting the second one.

LANGUAGE
--------
The program follows the Windows language (English or Portuguese). To
pick one: "Accounts" > "Language".

UPDATES
-------
Once a day the program checks GitHub for a new version (without sending
any of your data). When there is one, a discreet notice appears at the
top of the window and in the tray menu. "Update now" downloads the new
version, verifies the file and reopens by itself - the VPNs that were
connected reconnect right after.
To turn the check off: "Accounts" > uncheck "Check for new versions
automatically" (the "Check now" link is still there).

NOTES
-----
- On the first run, Windows SmartScreen may warn about an "unrecognized
  app": click "More info" and then "Run anyway".
- If two accounts send ALL internet traffic through the VPN, the
  program warns before connecting the second one: with both on, only
  the last one works as the default route.
- If the password is rejected, check the account's username and
  seed/password (or import the QR code again).
- If the interface does not open, check the diagnostics in
  %APPDATA%\VPN\startup-error.log.
- Each connection's log is kept in %APPDATA%\VPN\logs\ (useful for
  support when a VPN does not connect).
- If the OpenVPN installation fails, the full log is in
  %APPDATA%\VPN\openvpn-install.log.
- The embedded installer is the official OpenVPN Inc. package, without
  modification; details in THIRD-PARTY-LICENSES.txt.
- Keep the seed/QR code as safe as a password: anyone who has the seed
  can generate your tokens.

UNINSTALLING
------------
The program has no installer: exit it (right-click the tray icon >
"Exit") and delete VPN.exe. To also delete the saved accounts and logs,
delete the %APPDATA%\VPN folder. If OpenVPN was installed by the
program, it can be removed under Windows Settings > Apps > Installed
apps > OpenVPN.

WHERE THE DATA IS STORED
------------------------
%APPDATA%\VPN\contas.dat (encrypted with your Windows account - nobody
else can read it, not even another user of the same computer). To
delete an account, use "Accounts" > "Remove".
